# L2M Boss Tracker — Telegram-бот 🎮

Бот отслеживает респауны рейд-боссов, ведёт таймеры по Simferopol (UTC+3), отправляет уведомления за 15 / 5 / 1 минуту и объявляет появление **всем подписчикам** (кто запустил `/list`).

**Формат времени:** `HH:MM` — абсолютное время респауна, без "через сколько".

## Быстрый старт

### 1. Токен бота

Создайте бота через [@BotFather](https://t.me/BotFather), скопируйте токен и вставьте в файл **`.env`** в корне проекта:

```bash
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
```

### 2. Админы

В файл **`admins.txt`** (корень проекта) добавьте ID или username админов (по одному на строку):

```
123456789
@your_username
```

**Только админы** могут использовать команды `/kill`, `/restart` и все admin-команды.

### 3. Установка и запуск

**Автоматический запуск (рекомендуется):**
```bash
./start_bot.sh
```

**Остановка бота:**
```bash
./stop_bot.sh
# или просто Ctrl+C в терминале
```

**Ручная установка:**
```bash
pip install -r requirements.txt
python create_db.py
python -m app.seed --reset
```

Флаг `--reset` создаёт БД заново и заливает 54 босса.

### 4. Запуск бота

```bash
python bot.py
```

Токен читается из `.env`, админы — из `admins.txt`.

## Команды

### Для всех пользователей

| Команда | Описание |
|--------|----------|
| `/help` или `/start` | Показать список команд с примерами. |
| `/list` | Список боссов с абсолютным временем (HH:MM:SS). У каждого босса кнопка "Босс убит". |
| `/test <ID>` | (скрытая) Отправить 3 тестовых сообщения с временем now+1/2/3 мин. |

### Для админов

| Команда | Описание |
|--------|----------|
| `/restart [время]` | Установить время рестарта сервера. Варианты: `now`, `HH:MM`, `DD.MM.YYYY HH:MM`. |
| `/kill <ID> [время]` | Зафиксировать убийство босса. |
| `/settings` | Админ-панель: управление боссами и админами. |
| `/boss_add <Имя> <Шанс%> <время>` | Добавить босса. Пример: `/boss_add Чертуба 50% 10h` |
| `/boss_del <ID>` | Удалить босса. |
| `/boss_edit <ID> <Имя> <Шанс%> <время>` | Редактировать босса. |
| `/admin_add @username` | Добавить админа. |
| `/admin_del @username` | Удалить админа. |

## Уведомления

Бот отправляет уведомления **всем подписчикам** (кто хотя бы раз запустил `/list`):

- ⚠️ За 15 минут: `⚠️ Через 15 минут респ:\n21:41:00 | 48 | Чертуба | 50%` + кнопка "Босс убит"
- ⚠️ За 5 минут: аналогично + кнопка
- ⚠️ За 1 минуту: аналогично + кнопка
- 🔴 В момент появления: `🔴 Босс появился:\n21:41:00 | 48 | Чертуба | 50%` → запускает новый цикл респауна

**Формат времени:** `HH:MM:SS` — абсолютное время респа (Simferopol, UTC+3).

Проверка раз в минуту (JobQueue).

## Структура

- `bot.py` — точка входа, команды и периодическая проверка уведомлений.
- `app/db.py` — SQLite, сессии.
- `app/models.py` — Boss, KillLog, ServerState.
- `app/services.py` — расчёт следующего респауна по Москве.
- `app/seed_data.py` — список из 54 боссов.
- `app/seed.py` — скрипт загрузки в БД (`python -m app.seed [--reset]`).
